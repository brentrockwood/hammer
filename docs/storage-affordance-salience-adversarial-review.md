# Storage-affordance salience calibration — adversarial review

## Decision

Run the matched two-arm calibration, not a broad wording search. The source-close boundary avoids the earlier idle/action-clock confound. The stop rule prevents this from becoming a study of arbitrarily many phrasings.

## Main threats and controls

- **The model never encountered the opportunity.** Source acquisition is recorded before recognition; it is not collapsed into a negative recognition result.
- **The final answer is mistaken for support state.** `/work/answer` is cleared at the boundary and excluded from qualifying support paths.
- **A file exists but is not useful.** Recognition and post-boundary reread are separate measures. A support file without the later exact read is not utilization.
- **The arms differ in more than salience.** They share the same source-close trigger, source deletion, transcript replacement, fixture, action grammar, budgets, model, and terminal policy. The sole task-text difference is the explicit preservation sentence.
- **A one-run file is overstated as a tool.** Reports call it an ephemeral support artifact. No run in this calibration establishes reusable infrastructure or a performance advantage.
- **Sampling noise is interpreted as a threshold.** Six members per arm are a screen, not an estimate. Only a mixed consequences result receives additional repetitions, using the unchanged prompt and apparatus.

## Remaining limitation

The task still makes the future need highly legible. That is intentional: this is an assay of salience under a declared boundary, not a test of whether a model invents reasons to persist state in an ordinary static task. A later task family must test transfer before any broader claim is considered.
