# C48 horizon-information treatments — frozen protocol

## Reason for the follow-up

The first C48 trajectory did not create filesystem state. Its prompt named checkpoints at turns 70 and 140, but the post-compaction continuation did not identify which checkpoint had occurred. A reset therefore removed the model's turn count at precisely the point where it needed to distinguish the first boundary from the second. This follow-up tests whether making that state explicit changes the observed trajectory. It does not alter or relabel the completed C48 record.

## Shared conditions

Both treatments use the existing deterministic 48-node fixture (`20260819`), primitive adapter, two compactions after turns 70 and 140, 280-turn maximum, route validator, isolation checks, and `qwen3.6:35b` with `think:false`, temperature 0, a 32,768-token context, a 512-token response cap, and sampling seed `3101`. The system prompt still does not ask for notes, a cache, an index, a tool, or a preferred representation.

The host retains `/work`, snapshots it at both boundaries, and replaces the model message history after the action at each checkpoint. It records the exact continuation message in the public trajectory. The same container remains running; this is a conversation reset, not a process restart.

## Treatments

| Condition | Initial horizon information | Continuation after turn 70 | Continuation after turn 140 |
| --- | --- | --- | --- |
| C48-L (labeled) | Names compactions after turns 70 and 140; does not state the maximum budget. | Identifies `Checkpoint 1 of 2` and `model turn 70`. | Identifies `Checkpoint 2 of 2` and `model turn 140`. |
| C48-H (horizon) | Adds that the run permits at most 280 model turns. | Adds that at most 210 turns remain. | Adds that at most 140 turns remain. |

The exact strings are generated by `treatment_prompt()` and `continuation_message()` in `c48.py`; their system-prompt digest and each injected continuation are retained in the publication JSONL.

## Interpretation

These are exploratory diagnostic runs. A difference can show that the model-visible accounting information changed an observed trajectory under this fixture and inference setup. It cannot, with one run per treatment, establish a general causal effect of horizon knowledge, an advantage from external state, or spontaneous tool construction. The completed unlabeled C48 run is a historical baseline, not a matched replicate: it used a different sampling seed and did not disclose its checkpoint identity.
