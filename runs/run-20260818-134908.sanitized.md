# Initial syscall retrieval spike

We wanted to know whether the model could orient itself in the scratch environment and recover a value without a shell or a `read_file` convenience tool.

The container held only the static agent and `/work`. The model received the syscall action grammar, then enumerated `/work`, opened `message`, read the bytes, closed the descriptor, and returned `PUBLIC_TEST_VALUE_HAMMER_001`.

The run passed. More importantly, the trajectory was short and unsurprising: the model mapped the task onto `getdents64`, `openat`, `read`, and `close` without needing corrective prompting.
