# Persistence and restart apparatus validation

We wanted to separate environmental persistence from conversational memory. Generation 1 therefore wrote a public marker into `/work`; we destroyed its container and discarded its model context. Generation 2 started in a distinct network-disabled container with the same mounted `/work` and a fresh transcript.

The run passed. Generation 2 enumerated `/work`, found `persisted`, opened it, and reported `PUBLIC_PERSISTENCE_MARKER_HAMMER_001`. The host independently verified the exact bytes, distinct container identities, and disabled network mode in both generations.

There was one useful protocol mistake. After correctly writing and closing the marker, generation 1 returned the literal placeholder `EXACT ANSWER` instead of `created`. The prompt had made that phrase look like a valid answer. It did not affect the persistence test, but the full record preserves it; later prompts use an explicitly bracketed placeholder.
